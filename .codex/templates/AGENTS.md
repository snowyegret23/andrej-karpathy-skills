# AGENTS.md

상위 Codex 지침, 현재 사용자 요청, 보안/권한 정책이 우선한다. 이 파일에는 프로젝트에 남길 규칙만 둔다.

## 기본 원칙

- 사용자에게는 한국어 존댓말로 답한다.
- 가정과 불확실성을 숨기지 않는다.
- 요청받지 않은 기능, 추상화, 범용화를 추가하지 않는다.
- 기존 사용자 변경을 되돌리지 않는다.
- 막히면 회피하지 말고 새 가설, 검색어, 증거 경로를 바로 시도한다.
- 성공 기준과 검증 방법을 정하고 실제 결과를 확인한다.
- 명확한 요청은 별도 계획 문서나 승인 단계 없이 바로 수행한다.
- 사용자가 명시하지 않으면 계획/명세 문서, 새 테스트 파일, worktree, subagent를 생성하지 않는다.
- Windows Python 명령은 Store 별칭을 제외하고 해석한 실제 인터프리터를 사용하며 사용자별 절대경로를 규칙에 하드코딩하지 않는다.
- 필요한 외부 도구는 `_external/`에 두고 직접 설치, 빌드, 검증한다.

## 루트 문서

- `AGENTS.md`: 에이전트 규칙. 루트의 유일한 agent rule 문서로 둔다.
- `WORK.md`: 현재 큐와 최근 완료 작업. 세션 시작 시 가장 먼저 본다.
- `MEMORY.MD`: 프로젝트 누적 상태와 작업 기록.
- `GHIDRA.md` 또는 리버싱 문서: 디컴파일, 디버깅, 런타임으로 확정한 사실.
- `STRUCTURE.md`: 파일 포맷, 로더, 재구축 계약.
- `NEXT_SESSION_MESSAGE.md`: 다음 세션 첫 메시지.
- 번역 규칙 문서: 공통/파일별 번역, 검수, 제어코드 규칙.
- 루트에는 인계 문서만 둔다. 오래된 로그와 일회성 스크립트는 `_analysis/` 또는 `tools/` 관례 위치로 옮긴다.

## 작업 규칙

- 세션 시작 시 `WORK.md` -> `MEMORY.MD` -> 리버싱 문서 -> `STRUCTURE.md` 순서로 읽고 `git log --oneline -15`를 확인한다.
- 구조 변경 전에는 관련 구조 문서와 `_analysis/` 노트를 읽는다.
- 번역/검수는 프로젝트별 규칙을 먼저 읽고 제어코드, placeholder, token, 표시 규칙을 보존한다.
- 원본 보관 위치는 읽기 전용이다. 변경은 복사본이나 산출물에만 적용한다.
- `_analysis/`는 분석/검증 기록, `editable_files/`는 사용자 편집 입력, `tools/`는 재현 가능한 도구로 구분한다.
- 새 구조 사실, 툴 상태, 런타임 사실, 검증 결과는 해당 상태 문서에 기록한다.
- 모르는 것은 모른다고 적고, 추정은 추정이라고 표시한다.
- 기존 툴의 주석, 테이블, 휴리스틱은 증거가 아니다. 원본 데이터, 디컴파일, 런타임 관찰, raw dump를 우선한다.
- 정적 분석이 부족하면 Ghidra, 에뮬레이터, 디버거, 로그, 패턴 검색으로 확인한다.
- 작업에 맞는 플러그인, MCP, 외부 도구는 사용자가 이름을 말하지 않아도 주도적으로 사용한다.
- 큰 파일 묶음은 무작정 열기 전에 검색, 요약, 패킹 도구 사용을 고려한다.
- 완료 전 가능한 범위에서 roundtrip, growth, re-export, 실제 빌드를 검증한다.
- 무거운 스캔은 쪼개서 실행하고 실패 원인과 부분 산출물을 기록한다.
- 대용량 바이너리와 빌드 산출물은 Git에서 제외하고, 분석 문서와 재현 스크립트는 추적한다.

## 편집/검증

- hook 또는 skill을 바꾸면 대표 payload로 직접 실행한다.
- Python hook을 바꾸면 `py_compile` 대신 cache 없는 `compile()` 검증을 실행한다.
- 문서와 설정을 바꾸면 `git diff --check`를 실행한다.
- 검증 중 생긴 `__pycache__` 같은 생성물은 정리한다.

## 커밋

- 작은 의미 단위가 완료되고 검증되면 커밋한다.
- 커밋 전 `git status --short`, 변경 범위, 검증 결과를 확인한다.
- 관련 없는 사용자 변경은 커밋에 섞지 않는다. 분리할 수 없으면 커밋하지 말고 상황을 보고한다.
- 검증 실패, git 작업 진행 중, 변경 목적 불명확 상태에서는 커밋하지 않는다.
- 커밋 메시지는 의미 있는 영어로 작성한다.
